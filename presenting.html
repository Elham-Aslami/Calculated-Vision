Before the presentation

  1. Open your published website. Use the website address shown in your repository’s Settings → Pages. Check the link on the presentation computer before the pitch.
  2. Let the CAD model finish loading. Select Explore in 3D and wait for “LIVE CAD MODEL.” Try the Entrance and AC end views, rotation, zoom, and fullscreen on the actual computer and display you will use.
  3. Keep the offline copy ready. Download and extract the ZIP in advance. It includes the model, images, scripts, source PDFs, and all 3D dependencies.
  4. Test the inquiry demonstration. Use sample details, prepare the inquiry, and download it. Nothing is sent to the team.

The source and CAD checks pass, but interactive browser testing was unavailable in the build environment. A rehearsal on the presentation device is still needed, especially for WebGL, touch gestures, and fullscreen.

A simple demo walkthrough

  1. The idea. Begin with “A cooler break, closer to the work.” Explain the one-person shelter and its external electrical supply.
  2. The actual design. Open the viewer, rotate the model, and select the three numbered features. The silver body and orange module are visual styling on the supplied CAD.
  3. How cooling works. Explain the two separate air paths: cooled air returns to the shelter; heat is released outdoors. The airflow illustration is conceptual.
  4. The people behind the decisions. Show the interview feedback and development roadmap.
  5. The next step. End with the preliminary price range and interest in future pilots or prototype support. Full-size performance has not yet been validated.

Run the downloaded website

Extract the entire ZIP first. On Windows, double-click run-windows.cmd if Python or Node.js is installed. Keep the terminal open and visit http://localhost:8080.

Or open a terminal in the extracted folder and use one of these commands:

  • Python on Windows: py -m http.server 8080 --directory .
  • Python on macOS/Linux: python3 -m http.server 8080 --directory .
  • Node.js: node server.mjs

Use a local server instead of double-clicking index.html. Browsers restrict 3D module and model loading from a local file URL. Once extracted and served locally, the website needs no internet connection. Do not run two servers on the same port.

Viewer controls

  • Mouse: drag to rotate. Use the + and − buttons to zoom. Clicking the model also enables wheel zoom.
  • Keyboard: Tab into the viewer; use arrow keys to rotate, + / − to zoom, and R to reset.
  • Touch: tap “Tap to interact with the model,” then drag or pinch. Select “Done exploring” to return to normal page scrolling.
  • Automatic rotation: use the Auto-rotate switch. It starts off and stops when you interact.
  • Fullscreen: use the expand button; Escape exits. If native fullscreen is unavailable, the viewer expands within the page.

The site respects reduced-motion preferences and keeps written information available while 3D loads.

Keep the product information current

Edit index.html for specifications, team, pricing, and main copy; content.js for interactive feature descriptions and audience text; and styles.css for appearance. The README explains publishing, the source files, and how to connect a real inquiry destination. You can download your source again from your GitHub repository using Code → Download ZIP.

The source PDFs remain available for reference: current design plan and team presentation. The design plan takes priority for engineering decisions.
